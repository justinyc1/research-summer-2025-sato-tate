# $\text{ST}(\text{Jac}(\text{C}_{p^2}))/\text{ST}^{0}(\text{Jac}(\text{C}\_{p^2}))$

This folder contains the code used in regards to $\text{ST}(\text{Jac}(\text{C}\_{p^2}))/\text{ST}^{0}(\text{Jac}(\text{C}\_{p^2}))$--the component group of $\text{ST}(\text{Jac}(\text{C}\_{p^2}))$.

- `functions.sage` is a (small) documentation of major functions used
- `example.ipynb` is a demonstration of computing a generator of the component group
