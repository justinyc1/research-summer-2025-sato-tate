# The Component Group $\text{ST}(\text{Jac}(\text{C}_{p^2}))/\text{ST}^{0}(\text{Jac}(\text{C}\_{p^2}))$

This folder contains the code used pertaining to the component group of $\text{ST}(\text{Jac}(\text{C}_{p^2}))$.

## Installation and Prerequisites  

Please ensure to have the latest version of Sage/SageMath installed.

> Tested with version 10.7

An official installation guide can be found [here](https://doc.sagemath.org/html/en/installation/index.html#) for Windows, macOS, and Linux-based users.  

## Organization

- `component_group_generator.sage` contains the (Sage) function used to compute a generator of the component group.
- `example.ipynb` is a demonstration of computing a component group generator for $p=5, 7$.
